DESCRIPTION : 

GREEN BALL est un jeu de basket en 2D qui se joue en duel. Après avoir choisi la difficulté, le but est de tirer vers un panier afin d'avoir le plus de point au bout des 3 manches tout ça avec un temps limité de 30 secondes pour chaque manche.

FONCTIONNALITES PRINCIPALES :
Sélection du mode de difficulté (facile, moyen, difficile), Saisie du nom des joueurs, système de score et de chronomètre, animation d'introduction, menus intéractifs, musiques, images de fond.

TECHNOLOGIES UTILISEES :

Utilisation de python, pygame, pycharm et github

2. Documentation technique :

ALGORITHME DU JEU : 

Affichage de l’écran de bienvenue avec un bouton JOUER, entrée des noms des deux joueurs, sélection de la difficulté, démarrage du jeu avec 3 manches, a chaque manche : un joueur tire, le score est calculé en fonction du panier, le temps est limité à 30 secondes, affichage du score final et de l'écran de fin, possibilité de rejouer ou retourner au menu.
